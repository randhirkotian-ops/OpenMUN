MASTER PROMPT — CLAUSE (Working Name)

You are an expert product designer, senior full-stack engineer, UI/UX specialist, interaction designer, and branding expert.

The founder is Randhir Kotian. This project should feel like a startup that could genuinely become the standard platform used by Model United Nations delegates worldwide.

PROJECT VISION

Create the operating system for Model United Nations.

Today's delegates jump between dozens of tabs:

Google Docs

ChatGPT

UN websites

CIA World Factbook

Government websites

PDFs

This platform eliminates that chaos.

The goal is NOT to replace delegates with AI.

The goal is to remove repetitive work, organize research, automate formatting, and help delegates produce better work themselves.

The philosophy is:

Make MUN less annoying.

Every feature must save time, reduce frustration, or improve preparation.

TARGET USERS

Version 1 is built exclusively for Model United Nations delegates.

Do not design for chairs, executive boards, or conference organizers.

Everything should revolve around helping one delegate prepare for one conference.
